## Naming Conventions Used

### Entity Files
```
[Entity].cs
Example: Category.cs, Skill.cs, JobPost.cs
Location: src/Core/Istapio.Domain/Entities/
```

### DTO Files
```
Get[Entity]Dto.cs
Create[Entity]Dto.cs
Update[Entity]Dto.cs
Example: GetCategoryDto.cs, CreateCategoryDto.cs, UpdateCategoryDto.cs
Location: src/Core/Istapio.Application/Models/DTOs/[Entity]/
```

### Service Files
```
I[Entity]Service.cs (interface)
[Entity]Service.cs (implementation)
Example: ICategoryService.cs, CategoryService.cs
Location: 
  - Interface: src/Core/Istapio.Application/Services/Internal/Interfaces/
  - Implementation: src/Core/Istapio.Application/Services/Internal/Implementations/
```

### Controller Files
```
[Entities]Controller.cs
Example: CategoriesController.cs, SkillsController.cs, JobPostsController.cs
Location: Presentation/Istapio.API/Controllers/
```

### Validator Files
```
Create[Entity]DtoValidator.cs
Update[Entity]DtoValidator.cs
Example: CreateCategoryDtoValidator.cs, UpdateCategoryDtoValidator.cs
Location: src/Core/Istapio.Application/Validators/[Entity]/
```

### AutoMapper Profile Files
```
[Entity]Profile.cs
Example: CategoryProfile.cs, SkillProfile.cs, JobPostProfile.cs
Location: src/Core/Istapio.Application/Profiles/
```

## How to Navigate the Code

### Finding a specific entity's implementation:
1. DTOs: `src/Core/Istapio.Application/Models/DTOs/[Entity]/`
2. Service Interface: `src/Core/Istapio.Application/Services/Internal/Interfaces/I[Entity]Service.cs`
3. Service Implementation: `src/Core/Istapio.Application/Services/Internal/Implementations/[Entity]Service.cs`
4. Controller: `Presentation/Istapio.API/Controllers/[Entities]Controller.cs`
5. Validators: `src/Core/Istapio.Application/Validators/[Entity]/`
6. AutoMapper Profile: `src/Core/Istapio.Application/Profiles/[Entity]Profile.cs`

### Adding a new endpoint:
1. Add method to Service Interface (if creating new operation type)
2. Implement in Service Implementation
3. Create/Update DTO if needed
4. Add validator if creating new operation
5. Add corresponding Controller method

### Troubleshooting validation errors:
1. Check DTO structure in `Models/DTOs/[Entity]/`
2. Review validator in `Validators/[Entity]/`
3. Verify AutoMapper profile in `Profiles/[Entity]Profile.cs`
4. Check service implementation for mapping logic
